# TestTracks

TestTracks is a collection of starter test automation frameworks for different languages and stacks.
Each folder is a separate implementation with its own setup guide, examples and project structure.

## Projects
- [playwright-csharp](./playwright-csharp) - Windows-focused C# Playwright starter framework for browser and API testing with Reqnroll (BDD), environment-based test data, page objects, API clients, cleanup, reports, and GitHub Actions.

## Purpose

The goal is to provide practical, clean examples of how to structure test automation projects that can grow with real teams and real applications.

Each implementation is intentionally small enough to understand, but complete enough to show:

- environment-based test data
- API and UI testing
- page objects or equivalent UI models
- reusable API clients
- scenario-owned cleanup
- test reports and evidence
- CI setup

## Notes

Each project has its own README. Start there for installation, running tests and project-specific details.
